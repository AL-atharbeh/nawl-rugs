# نَوْل — معرض السجاد اليدوي (مشروع تجريبي)

موقع تجريبي من تصميم **شيفرا كود** لمعارض ومحلات السجاد.

- `index.html` — موقع المعرض: المجموعات، القطع المختارة، دليل المقاس التفاعلي، حجز زيارة.
- `story.html` — تجربة سينمائية تفاعلية «حكاية عُقدة» تُنسج فيها السجادة أثناء التمرير (فيها وضع تصوير تلقائي: اضغط F).
- `brand.html` — دليل الهوية البصرية.

> الاسم «نَوْل» والأسعار والعنوان والتقييمات بيانات تجريبية للعرض فقط.
